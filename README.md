# 狼人杀发牌与计时小程序

供线下狼人杀牌局使用的原生微信小程序。当前用于本机开发、微信开发者工具预览和手机自测，不包含联网房间、云服务、自动胜负判定或正式发布配置。

## 功能

- 玩家人数支持 6–12 人，可为座位填写昵称。
- 内置狼人、村民、预言家、女巫、猎人、守卫六种角色，可调整数量。开始前检查角色总数是否等于玩家人数，并要求至少一张狼人牌。
- 提供角色技能、限制和阵营胜利条件说明。狼人按屠边规则获胜：消灭全部神职角色或全部村民；好人消灭全部狼人获胜。
- 女巫首夜自救可按本局设置，默认关闭。守卫不能连续两晚保护同一人；守卫保护和女巫解药同时作用于同一名受袭玩家时，该玩家死亡。猎人被狼人袭击或投票放逐时可以开枪，被毒杀时不能开枪。
- 洗牌后按座位发放身份。查看身份前须验证本局 4 位主持人口令；退出查看模式后再次进入需要重新验证。可确认后重新洗牌，或确认结束本局。
- 发言计时支持 30、60、90、120 秒快捷时长及 10–600 秒自定义时长，可开始、暂停、重置、手动切换座位。倒计时归零后停止并提醒主持人确认进入下一位。
- 计时以截止时间计算，切到后台再返回时会按真实时间更新。
- 保存最近一次配置，包含人数、昵称、角色数量、女巫首夜自救选项和发言时长。
- 对局页可记录警长；第一天自动随机发言，之后有警长时由警长决定，无警长时按死亡玩家左右或死亡超过两人随机生成建议顺序，主持人可手动选择上一位或下一位。
- 对局页可按夜记录狼人袭击、守卫保护、女巫用药、预言家查验和最终死亡玩家；可按轮记录逐人投票摘要及被放逐玩家，死亡状态会用于后续发言顺序参考。

## 在微信开发者工具中运行

1. 使用微信开发者工具打开本项目目录。
2. 点击顶部“编译”，确认模拟器显示首页。
3. 点击“预览”生成二维码。
4. 在手机微信中使用“扫一扫”扫描二维码，打开小程序预览。

预览二维码用于开发自测，不等同于正式发布。若扫码提示无权限，请确认当前微信账号具有该小程序 AppID 的开发或体验权限。本项目不需要云服务。

## 基本测试流程

1. 在首页点击“开始游戏”。
2. 选择人数并填写昵称，调整角色数量，确认总数与玩家人数一致且至少有一张狼人牌。
3. 选择女巫首夜自救选项和发言时长，设置 4 位数字主持人口令后开始。
4. 在对局页测试计时器、手动切换座位和口令验证；验证通过后可查看任意座位身份，退出查看模式后再次进入需重新验证。
5. 测试重新洗牌与结束本局的确认提示，并验证首页最近配置仍保留。
6. 计时运行时切到手机后台，再返回对局页，检查剩余时间是否按真实时间更新。

## 本机数据与隐私

最近一次配置保存在本机微信小程序存储中，不包含主持人口令或身份牌。本局身份、身份查看状态和口令仅在小程序运行期间保存在内存中；结束本局时清除。应用进程关闭后，本局身份不会保留，需要重新开始。

请勿将密码、访问令牌、私钥或其他个人凭据提交到公开仓库。项目配置中的 AppID 用于微信开发者工具识别小程序。
